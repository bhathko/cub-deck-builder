# 簡報整體視覺規範

> 本檔分兩層:**排版紀律**(可編輯物件、Section 禁令、確認流程等)跨模板共用;
> **視覺常數**(字體、色碼、素材路徑、頁碼位置)以 light 模板包為基準,
> 機器真相在 `templates/<id>/manifest.json` 的 `style`——其他模板以其
> manifest 為準,本檔數值不適用於非 light 模板。

## 全域固定規範
- 最終輸出格式：`.pptx`
- 視覺風格參考:選定模板包的 `template.pptx`(預設 light,沙箱路徑
  `/mnt/data/templates/light/template.pptx`),作為主要模板
  - 模板優先級：最高
  - 若文字描述與模板衝突，以模板實際畫面為準
- 投影片必須使用 PowerPoint 原生可編輯物件製作，包括文字框、表格、圖形、線條與圖表。
- 禁止將整頁內容輸出成圖片後貼進 PowerPoint。
- 背景圖、logo、模板紋理可以是圖片素材，但頁面主要文字、表格與圖形必須可編輯。
- 中文字體：Microsoft JhengHei
- 英文字體：Helvetica
- 主文字色：#344252
- 次文字色：#68727E
- 主色：#58D494
- 輔色：#848BF2, #4AB7F9
- logo 固定放左下角，使用 `assets/logos/cathay_logo.png`
- 一般頁頁碼固定放右下角；封面、封底不顯示頁碼
- 輸出的 PPT 不得保留模板原本的 PowerPoint 章節 / Section；產出前必須清除所有章節分組，只保留投影片本身。

## 產出流程規則

> 2026-07-26 更新:本節原本描述舊管線的「先產逐頁預覽圖 → 停下來問使用者 →
> 才產正式 my_project.pptx」流程。該管線已於 2026-07-20 移除,現行規則如下
> (與 instructions 及 outline_to_ppt_skill 一致)。

- 產檔一律走 `tools/run_pipeline.py` 單一入口(稽核→驗證→渲染→QA),
  **不產預覽圖、不生任何圖片**;沙箱無中文字體,產不出可靠預覽,
  溢出要請使用者在 PowerPoint 開檔人工確認。
- 交付判準:管線最後一行 `管線結果:PASS`;qa 允許先有 WARN,警告如實回報。
- 產出檔名由使用者的 `--out` 指定(慣例 `deck.pptx`);**修計畫不修產出**——
  結果不對就改 spec/plan 整檔重跑,禁止對產出 pptx 局部修補。
- 一鍵大綱模式中途不得要求確認、不得拋 A/B 選單(規則已定案的事直接執行)。
- 若使用者只要求「寫規則」「調整設定」「修改 style_guide.md / page_types.md」,
  不可產出 PPT、不可啟動產檔流程。

## 模板元素拼版規範
- 若內容沒有明顯對應的頁型,不可自行發明新的視覺風格:先選頁型庫中結構最接近
  的頁型;仍不合適就回報使用者,由使用者決定改寫內容或換頁型(工具只支援
  「改字」與「刪除」,不支援拼湊模板元素組成新版面——同 page_types.md
  「版型選擇原則」)。
- 可重組使用的模板元素包含：白底細灰線圓角卡片、深色標題列、#58D494 重點標籤、#848BF2 / #4AB7F9 輔助標籤、淡綠色主題帶、箭頭階段列、垂直分類標籤、細灰分隔線、圓形節點、簡潔 icon 節點、表格格線與內容卡片。
- 卡片樣式優先使用白色底、淺灰色細線框、小圓角；若需要強調，可使用 #58D494、#848BF2 或 #4AB7F9 作為細框、標籤或小面積底色，不可改成模板外的新色系。
- 拼版時需維持模板既有的比例、留白、線寬、圓角、字級、字重與對齊方式；不可加入模板中沒有出現過的大陰影、厚重漸層、手繪插畫、3D 圖示、大面積裝飾圖或其他自創風格。
- 即使是拼湊版型，文字、卡片、表格、線條、箭頭、icon 節點與圖形也必須使用 PowerPoint 原生可編輯物件，不可把主要內容做成圖片。
- 若原模板頁型已經適合內容，只是文字太小或排版細節需調整，必須保留原模板的版型、比例、圖形位置、卡片樣式與視覺結構，只調整文字大小、行距、內容填入與必要的元素刪除；不可重新創造另一套版面。
- 特別注意：金字塔頁型若使用 light 模板第 54 頁或 `pyramid_layered_maturity_detail`，應保留原本斜向分層金字塔與右側說明卡片的模板結構，不可改成自製的大型橫條堆疊版面；若問題只是文字太小，僅放大文字並微調位置。

## 卡片、陰影與圓角規範
- 模板中的卡片大多為白底、淺灰細線框、小圓角、無陰影或極淡陰影；產出時必須貼近此樣式。
- 預設不得自行加入陰影。只有當來源模板同一頁型本身已有陰影時，才可使用同等或更淡的陰影。
- 禁止使用厚重陰影、深灰陰影、大面積投影、模糊半徑過大的陰影，或讓卡片看起來浮起來的強烈陰影效果。
- 除了深色標籤、頁籤、箭頭標籤、長條標籤等模板中的「標籤類元素」以外，所有卡片、資訊框、數字框、說明框、表格外框與內容容器都應使用小圓角。
- 卡片圓角必須小，需接近模板原件；不可使用大圓角、膠囊形圓角或與模板不一致的圓角比例。
- 若使用 PowerPoint 圓角矩形，圓角調整值應維持低比例；若模板原頁使用直角或近似直角，應使用直角或近似直角。
- 卡片框線以淺灰細線為主，建議使用 #D8DEE4 附近色階與 0.75-1 pt 線寬；不可使用粗框線或高對比黑框，除非模板原頁就是如此。

## 頁碼規範
- 一般內容頁必須顯示頁碼，固定放在右下角。
- 頁碼文字大小必須使用 `Page Number` 層級，也就是 28 pt；不可沿用模板中較小的頁碼字級。
- 頁碼顏色使用 #344252，不可使用過淡灰色導致看不清楚。
- 封面與封底不顯示頁碼；若故事情節頁面依模板規範不顯示頁碼，也必須確認該頁型規則允許。

## 封面規範
- 頁型名稱：`封面`
- 嚴格使用 `assets/backgrounds/cover_bg.png` 作為背景。
- 不可自行產生其他背景、圖示、產品圖或裝飾圖。
- 排版嚴格依照 light 模板第 7 頁的版型比例。
- 不需要顯示頁碼。
- Logo 放左下角，使用 `assets/logos/cathay_logo.png`。
- 封面主標題與重點大標必須做動態排版，避免任何文字掉字、重疊或被截斷。
- 若深色主標題加上重點大標可在同一行完整顯示，重點大標應接在主標題右側，並保留清楚間距。
- 若深色主標題長度已佔封面可用文字寬度約 1/2 或更多，導致重點大標無法同一行完整顯示，重點大標必須移到下一行，不可壓縮到掉字或與日期重疊。
- 當重點大標移到下一行時，封面日期、部門、報告人等下方內容必須同步往下移動，保留足夠行距，不可覆蓋標題。
- 封面標題區需要先計算文字寬度與可用空間，再決定單行或雙行排版；不可固定座標硬塞。

## 一般內容頁規範
- 使用 `assets/backgrounds/content_bg.png` 作為一般頁背景，不可自行新增其他裝飾物。
- 每頁只呈現一個主要訊息。
- 一般頁大標使用 H2。
- 核心訊息或頁面副標使用 H6。
- 內容標題使用 H4，再下一層級的標題使用 H5。
- 內文使用 p1 或 p2，禁止低於 p2 字級的大小
- 表格、卡片、節點、流程、線條都必須是可編輯物件。
- 不要塞滿文字；文字過多時優先拆頁或改成摘要。
- 版面需保留模板的留白感與對齊規則

## 封底規範
- 頁型名稱：`封底`
- 使用 `assets/backgrounds/cover_bg.png` 作為背景，不可自行新增其他裝飾物。
- 只保留 `Thank you`。
- 不要人名、不要其他說明文字、不要頁碼。
- `Thank you` 字級：32 pt，Bold，顏色 #344252。


## 色彩規範
- 主色： #58D494, #848BF2, #4AB7F9
- 強調色：#58D494，只用於關鍵數字與重點標籤
- 文字顏色 : #344252
- 背景色：避免全白太單調，可使用淺灰或淡色漸層
- 禁止：大面積紫色、大面積咖啡色、過度花俏彩虹色


## 圖表頁規範
- 若使用我提供的圖表，必須保留原始圖表內容
- 可以加上符合模板風格的標題、註解、重點框線
