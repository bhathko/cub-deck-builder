# 給設計師的說明 — 從這裡開始

> 這個資料夾是**寫給設計師與非技術同事**的,不講程式。
> 一份文件回答一件事,**只讀你需要的那份就好**,不用全部看完。

## 最近更新(2026-07-27)

**一句話:版位到底裝得下幾個字,以前算錯了,現在算對了——所以上限普遍變緊。**

| 變了什麼 | 對你的影響 |
| --- | --- |
| **字數上限重新量過,而且變緊** | light 封面主標從「20 字」變成「**7 字**」。不是規則變嚴,是以前量錯:量測程式讀不到「字級寫在版面配置裡」的框,一律當成 18pt,而封面主標實際是 40pt。整份模板有 **218 個框**都是這種框。 |
| **KPI 大數字框只能 2 個字** | 那個框在模板裡本來就寫「04」「25」兩位數。想寫「48 小時」要拆成數字放大框、單位寫在說明列。 |
| **封面/目錄/封底改成「模板裡真的要有那幾頁」** | 以前這三種是程式從空白頁畫出來的,現在一律 clone 你畫的頁。**交模板時記得把這三頁畫進去**,沒有的話那三種頁型就是「不支援」。好處是它們終於跟你的設計一致了。 |
| **產出檢查一鍵跑完** | 管理者那邊的事,你會感覺到的是:改動之後回報更快。 |

**這次是怎麼發現的**:拿系統實跑一份 10 頁的職場禮儀簡報,所有機器檢查全綠,
但用 PowerPoint 開起來,封面主標「職場禮儀新人訓練」折成兩行壓在副標上。
**再一次證明「機器綠 ≠ 版面對」,你們的目檢是唯一抓得到這種問題的關卡。**

> 交模板時值得記住的一句話:**標題框做多寬 ÷ 你設定的字級 ≈ 能寫幾個字**。
> 想讓標題能寫長一點,就把框做寬,或把字級調小——這兩件事只有你能決定,
> 系統不會偷偷幫你縮字。

## 交模板前,先看這張表:我能自己做到哪裡?

| | 這是什麼 | 誰可以做 |
| --- | --- | --- |
| **A. 交一整套新模板** | 給一個新 `.pptx`,讓它變成可選的模板 | **設計師可以自己發起**(走 02 或 03) |
| **B. 讓某個頁型在我的模板裡變全自動** | 那種頁型系統已經認得,只是我的模板還沒綁 | **一樣在 02/03 的流程內**,不必找工程師 |
| **C. 發明一種全新的頁型** | 系統從來沒有過的版面語意(例如「五欄比較表」) | **要找工程師**——會改到所有模板共用的規則 |

白話版:**「我的模板要支援某種頁型」可以自己來;「這世界上要多一種頁型」不行。**
分不清時就看:那種版面在**現有的全自動頁型**裡找得到相似的嗎?
(現有清單看「小菜單」`engine/rules/page_types_registry.md`,那是隨系統更新的活清單。)
找得到就是 B(自己來),找不到就是 C(先跟管理者提需求)。

## 路線 A 還是 B?

| | 路線 A:交給管理者 | 路線 B:我自己來 |
| --- | --- | --- |
| 你要做的 | 交檔、用嘴回答、開檔目檢 | 同左,再加上自己打指令 |
| 要開終端機嗎 | **不用** | 要 |
| 大概花多久 | 你這邊 15 分鐘 | 40–60 分鐘(第一次更久) |
| 適合誰 | 所有人。**不確定就選這條** | 想少一次來回、願意複製貼上的人 |

兩條路的產出**完全一樣**——同一套工具、同一份驗收檔。
路線 B 不會讓模板變好,只是不用等管理者。
